🎨 Design Justification

I designed a grouped bubble chart to represent all four required variables simultaneously. Region (nominal) is mapped to the x-axis position, grouping cities by geographic area. Temperature (interval) is mapped to the y-axis, allowing viewers to compare climate across regions. Population (ratio) controls the bubble radius using a square-root scale so that circle area is proportional to population, which is the perceptually correct way to encode magnitude. Development level (ordinal) is mapped to color using an intuitive red-yellow-green gradient from low to high. City names are labeled directly above each bubble, and tooltips reveal exact values on hover. This design was chosen because grouping by region makes it easy to spot geographic climate patterns, while bubble size and color together reveal how population and development relate to temperature within each region.
