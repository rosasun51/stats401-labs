This dataset was acquired by scraping books.toscrape.com, a website designed for practicing web scraping. The Python script (scrape_books.py) uses requests and BeautifulSoup to extract book information across 50 pages. Each request includes a 1-second delay for rate limiting, and errors are handled gracefully with try/except blocks. The script respects the site's robots.txt and terms of service.

Attributes: Title, Price (£), Rating (1–5 stars), Availability.
