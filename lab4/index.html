This lab uses a dataset of 1,000 tweets published on Mendeley Data (DOI: 10.17632/2sjt22sb55.1). It contains tweet text, user, timestamp, likes, retweets, and a provided sentiment label. The dataset is intentionally clean but we still apply a full cleaning pipeline to practice real‑world data wrangling.

Cleaning steps: dropped any rows with missing tweet text (none were missing); removed duplicates (none were exact duplicates, but we deduplicated by tweet_id); converted likes/retweets to numeric (handled commas and negative values); parsed dates into datetime and extracted weekday/hour; standardized columns (platform set to “Twitter”, country to “Unknown”); and recomputed sentiment using the RoBERTa‑based Transformer model (cardiffnlp/twitter-roberta-base-sentiment-latest) to estimate negative/neutral/positive probabilities and a continuous sentiment score.

📊 Sentiment Visualization

📝 Analysis

I used the 1,000‑tweet dataset from Mendeley Data, which includes tweet text, timestamps, likes, retweets, and a human‑generated sentiment label. After cleaning (no missing texts, no duplicates, consistent types, parsed dates), I performed sentiment analysis using the RoBERTa model fine‑tuned for Twitter sentiment. The model outputs probabilities for negative, neutral, and positive; I then derived a categorical label (the highest probability class) and a numeric score = P(positive) − P(negative).

The left bar chart shows the distribution of sentiment by platform. Since all tweets in this dataset come from Twitter, the platform is uniform, but the chart still demonstrates the overall sentiment breakdown: a large proportion of Positive tweets, followed by Neutral and Negative. The right line chart displays the average sentiment score by weekday. Scores are slightly above zero on most days, indicating generally positive sentiment, with a small dip on weekends (Saturday and Sunday). This pattern might reflect that users express less positive sentiment during leisure days, or it could be due to dataset randomness. Overall, the visualizations effectively combine sentiment with a time‑based attribute (weekday) and show that sentiment remains relatively stable across the week.

Note: Sentiment labels here are model‑generated estimates, not ground truth. The RoBERTa model is state‑of‑the‑art but can still misinterpret sarcasm or context.
