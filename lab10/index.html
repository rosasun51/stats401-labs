Lab 10: Novel Interaction with Visualizations

Voice-Controlled 2025 GDP Maps — extends Lab 9

📁 1. What I Extended

This lab reuses my Lab 9 geospatial visualization: a choropleth (color = 2025 nominal GDP, true geography) and a cartogram (area = 2025 GDP) of the top-50 economies, joined to world boundaries via ISO-3 identifiers. The data are the same data/lab9_gdp_2025_top50.csv file (IMF WEO, October 2025).

On top of the existing mouse interaction (hover tooltips, linked highlighting, zoom/pan), the maps below now accept voice commands. Conventional controls are still provided, so the page remains fully usable if speech recognition is unavailable.

🎙️ 2. Voice Control

Click Start Voice Control and say a command (the microphone is only activated by this explicit click, after which the browser asks for permission). The page always shows what it heard and what it did. If voice is not supported (e.g. some browsers) or permission is denied, use the buttons or type a command — they run the exact same functions.

Commands: "Show Europe" (also Asia, Africa, Americas, Oceania) • "Highlight China" (any top-50 country) • "Zoom in" / "Zoom out" • "Reset zoom" • "Reset" (clear filter + selection + zoom).

Voice control inactive — click the button, or use the controls below.

🗺️ 3. 2025 GDP Choropleth — Color = GDP

Real geographic boundaries, color encodes 2025 nominal GDP on a log scale. Voice filters dim everything outside the spoken region; a highlighted country gets a bright outline in both maps.

Darker/bluer → larger GDP (log scale) • dark gray = no data (outside top 50). Scroll to zoom, drag to pan.

🌐 4. 2025 GDP Cartogram — Area = GDP

The same data with area distorted so each country’s size reflects its GDP. Voice highlighting works here too — useful because distortion makes countries hard to recognize.

Country area is proportional to 2025 nominal GDP. Only the 50 economies with data are shown.

🪞 5. Design Reflection

I extended my Lab 9 geospatial visualization, the 2025 GDP choropleth and cartogram, with voice interaction. Saying “Show Europe” filters the map by region, “Highlight China” selects a country and reports its GDP and rank, “Zoom in”, “Zoom out” and “Reset zoom” control the view, and “Reset” clears everything.

The task it supports is hands-free exploration: presenting the maps to someone without touching the mouse, or helping users who struggle with fine cursor control. Voice fits this task because filtering and naming are naturally verbal acts — saying “highlight Japan” is faster than hunting for Japan with a cursor on a crowded map. I chose voice over gesture or gaze because the Web Speech API needs no model files and runs on GitHub Pages HTTPS, while webcam libraries are heavy and gaze is too noisy for precise selection.

Limitations: recognition works reliably only in Chrome or Edge, it needs microphone permission, and country names are sometimes misheard (“Turkiye”, “UAE”). Buttons and a typed-command box are the conventional fallback, so the page stays fully usable without a microphone.
