🚇 Dataset: Urban Transit Network

This synthetic dataset models a medium-sized city with 50 stations across five districts (Central, North, South, East, West) and 50 direct transit connections. Each station has a daily passenger volume and a functional type (Local, Transfer, Terminal). Each route has a travel time and a service type (Metro, Express, Shuttle).

🎨 Node-Link Design Description

I encoded district with node color using a distinct hue per district (red=Central, blue=North, etc.), making geographic grouping immediately visible. Daily passengers controls node size via a square-root scale so that area is proportional to volume—larger stations literally stand out. Station type is encoded as shape: circles for Local, squares for Transfer, and diamonds for Terminal, allowing viewers to spot functional roles without relying solely on color. For links, travel time maps to stroke width (longer routes are thicker) and route type maps to color (cyan=Metro, pink=Express, gray=Shuttle). Interaction includes draggable nodes, neighbor highlighting on hover, and tooltips showing station metadata.

🔲 Adjacency Matrix

Stations are ordered by district. White grid lines separate districts. Hover cells for route details.

🎨 Matrix Design Description

The adjacency matrix uses the same node ordering as the node-link diagram: stations are sorted by district (Central → North → South → East → West), creating visible block structures along the diagonal. Each row and column represents one station; labels are colored by district. A filled cell indicates a direct connection. Cell color encodes route type (Metro/Express/Shuttle) and cell opacity encodes travel time (darker = longer). Empty cells use a near-transparent fill. White separator lines between districts make it easy to see intra-district vs. cross-district connections. This ordering reveals that most connections cluster within districts, with sparser off-diagonal blocks representing cross-district routes.

❓ Network Questions & Findings

QuestionBest ViewEncoding UsedObservation
1Which stations appear central? Node-link Node size + degree (tooltip) Central district stations and large Transfer squares tend to have the most connections. In the force layout, they are pulled toward the center by multiple links, and tooltips confirm higher connection counts.
2Which districts are strongly connected? Both Matrix blocks + link colors The matrix shows dense diagonal blocks, meaning each district is strongly connected internally. Off-diagonal blocks are sparser. The node-link view confirms this: same-color clusters are tightly knit, with occasional cross-color bridges.
3Where are Transfer/Terminal stations? Node-link Node shape Transfer squares and Terminal diamonds are scattered across all districts but tend to sit at the boundaries between color clusters in the force layout, suggesting they bridge sub-communities. Terminal diamonds are the rarest and often have high passenger counts.
4Which stations have high passenger volume? Node-link Node size The largest circles/squares/diamonds are immediately visible. Central district contains several of the largest nodes, and Terminal stations (diamonds) are consistently among the top passenger volumes.
5Where are the longest travel-time connections? Both Link width / cell opacity In the node-link view, the thickest strokes often stretch between districts. In the matrix, the darkest cells appear in off-diagonal blocks, confirming that cross-district routes tend to have longer travel times.
6Are route types concentrated in particular areas? Both Link color / cell color Metro (cyan) links are distributed fairly evenly. Express (pink) routes appear more frequently in the Central and North districts and as cross-district connections. Shuttle (gray) routes are more common within peripheral districts (East/West), suggesting shorter local coverage.
