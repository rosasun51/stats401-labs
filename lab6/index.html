🌍 Dataset: Global GDP Hierarchy

This dataset contains 46 countries across 6 continents and 14 subregions (areas). Each leaf node records GDP in billions of USD and a status label (Increase, Unchanged, or Decrease). A Python script (convert_gdp.py) groups the flat CSV by continent → area → country into a nested JSON file for D3 hierarchical layouts.

Hierarchy: World → Continent → Area → Country
Quantitative value: GDP (billions USD)
Categorical value: GDP status (Increase / Unchanged / Decrease)

🎨 Design Description

I chose area to encode GDP amount because treemaps naturally represent part-to-whole relationships through rectangle size—larger economies literally occupy more space. GDP status is encoded with color using an intuitive traffic-light scheme: green for Increase, amber for Unchanged, and red for Decrease. This makes it easy to spot economic trends at a glance.

The two treemaps use different tiling strategies. Squarify produces rectangles with aspect ratios closer to squares, making individual countries easier to compare and label. Binary recursively splits the available space into two groups, creating a more structured, sliced appearance that emphasizes the hierarchical grouping at each level. Squarify is better for readability of individual items, while Binary more clearly reveals the recursive subdivision logic of the hierarchy.
